# Sable v1.0.0-alpha.1

An early native Windows PDF reader, ported from NightPDF with WinUI 3,
PDFium and the original night filters. This is a preview for testing.

## In this preview

- PDFs in tabs, with thumbnails, page labels and password prompts.
- Text selection/copy, Find, outlines, links and attachment saving.
- View rotation, hand panning, scroll/spread layouts and presentation mode.
- Two-finger trackpad scrolling and pinch zoom, with sharp PDF rendering.
- Optional left/right page clicks to turn spreads in Page scrolling.
- Document properties and Save a Copy, preserving the loaded PDF bytes.
- Windows print preview and original-color printing.
- Refined General, Shortcuts and About pages in Settings.
- Obsidian (AMOLED), with pure-black resting app surfaces and a saved choice.
- A music pane for Spotify and Apple Music sessions exposed by Windows.

## Downloads and running

Choose the x64 ZIP for Intel/AMD Windows PCs, or the ARM64 ZIP for Windows
on ARM. Extract the entire folder, then run Sable.exe. Keep the DLLs,
resources, assets, styles and language folders beside it. The ZIP includes
the Windows App SDK runtime; it is not a standalone EXE download.

There is no installer, file-association registration or automatic updater
in this preview. Settings and logs use the normal Sable application-data
folders. Closing and replacing the extracted app folder updates the app.
Keep the old folder until the new one has been checked.

SHA256SUMS.txt lists the archive hashes. Each ZIP also has a manifest with
file hashes and source provenance; the source ZIP includes the build and
dependency-fetch scripts. A filename containing `-local-` is a local review
candidate, not a release built from a tag.

## Validation and known limitations

The complete x64 Debug and Release suites each pass 453 tests; one hard-link
alias test is skipped because Windows denies the operation in this session.
All four x64/ARM64 builds pass without warnings, with normal Release LTO.
Twenty-five native checks pass, including the 1,000-page zoom regression.
The full tab/drop check stops at denied storage-broker access; its earlier
tab cases and the independent window checks pass. ARM64 has been compiled
but has not been run on an ARM64 machine.

The reliability pass fixed a printing shutdown use-after-free, a separate
test-runner factory lifetime crash, and two zoom/navigation transitions.
Five shuffled full suites per normal configuration, three full sanitizer
suites and fifty focused printing repetitions pass. The sanitizer checks
Sable's test-linked code; prebuilt dependencies are not fully instrumented.
The opt-in Windows PDF-driver check also passes in Debug and Release for
selected pages, paper sizes, original colors, annotations and rotation.
See docs/TEST_PLAN.md for the test record and its limits.

Physical keyboard/pointer/trackpad input, save/print dialog choices, real
Spotify/Apple Music sessions, notification delivery and monitor changes need
desktop sign-off. Local package startup does not replace a clean Windows
machine check. The source guide has the detailed checks in
docs/READER_CHECKS.md and docs/RELEASING.md.

Very tall document surfaces can reach the current graphics limit; the
reader shows an error rather than allocating an oversized surface. PDF
layers are deferred because the pinned public PDFium API lacks visibility
controls. Forms, annotations, editing and signing are outside this preview.

## Before publication

Keep this release as a draft until the desktop and clean-machine checks
have been recorded and the dependency-license review in
THIRD_PARTY_NOTICES.md has been resolved. In particular, the downloaded
PDFium license bundle contains Apache-2.0 text and the Windows runtime
packages supply Microsoft Software License Terms. Bundling those notices
does not resolve the distribution question. The release workflow creates
a draft prerelease and does not publish it automatically.
